===========================
Проект: HA Cluster UDP (Windows версия)
===========================

📁 Состав:
- time_server.py — сервер времени (использует порты)
- intermediary.py — сервер-посредник (порт 5555)
- client.py — простой UDP-клиент
- config/cluster_config.json — конфигурация координатора

===========================
🚀 Инструкция по запуску:
===========================

1. Запустите 3 сервера времени в 3 разных терминалах:

   python time_server.py 5551
   python time_server.py 5552
   python time_server.py 5553

2. Запустите посредника:

   python intermediary.py

3. Запустите клиента:

   python client.py

===========================
📌 Как работает:
===========================

- Координатор определяется по наибольшему порту
- В случае сбоя — проводятся выборы
- Посредник перенаправляет запросы клиент → координатор
- Все работает через 127.0.0.1 и разные порты
