Как играть в игру с автоматом игрушек

Эта страница поможет вам разобраться, как использовать игру с автоматом игрушек с помощью описания каждого шага и приложенных изображений.

Шаг 1: Запустите игру

Вам сразу представиться основной вид симулятора.

Шаг 2: Отображение гайда

При необходимости польльзователь может открыть гайд в самой игре, нажав на кнопку "Гайд" в левом верхнем углу экрана.

Шаг 3: Сбор монеток

С помощью кноки "Монетки", перемещаемся к монетам, лежащим на тумбочке, чтобы пополнить своё количество для игры.

Шаг 4: Вставляем монетки в игровой автомат

Для запуска игры неоходимо вставить монетку в игровой автомат. Одна монетка - одна попытка.

Шаг 5: Начало игры

Теперь у пользователя есть возможность в течение 25 секунд вытянуть игрушку. С помощью клавиш WASD осуществляется передвижение клешни для выбора игрушки.

Шаг 6: Ловим игрушку

Затем, чтобы опустить клешню и словить игрушку необходимо нажать Space.

Шаг 7: Забираем приз

Если получилось вытянуть игрушку, и она попала в отсек для выигршей, то необходимо кликнуть по ней мышкой.

Шаг 8: Неудачная попытка

Если у пользователя не получилось вытянуть игрушку, стоит попробовать ещё раз. Для этого повторяем все шаги сначала🙂🙂🙂

Шаг 9: Просмотр статистики

В приложении есть таюлица, в которой сохраняются результаты 6 игр. Пользователь может просмотреть данные нажав на кнопку "Таблица".
